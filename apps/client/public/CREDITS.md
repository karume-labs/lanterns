# Lanterns - Credits

## Original work

- Game design, code, pixel art direction, and writing created for this project.
- All sprites and interface art are generated from original pixel definitions
  in this repository (see `tools/` sprite tooling).

## Fonts

- Silkscreen (headings) - SIL Open Font License 1.1 - `fonts/OFL-Silkscreen.txt`
- Pixelify Sans (body and numbers) - SIL Open Font License 1.1 -
  `fonts/OFL-PixelifySans.txt`

## Audio

- All sound effects and music are original, synthesized by the repository's
  audio generator. Recipes and seeds are logged when the audio pass lands.

## Tools

- Built with Bun, Vite, React, Pixi.js, zustand, and Howler.js.
